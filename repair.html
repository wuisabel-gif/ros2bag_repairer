ros2bag-repairer · browser tool

Rebuild a missing metadata.yaml, right here.

Drop in the .db3 from a bag that lost its metadata.yaml (recorder crashed, power cut, Ctrl-C too early). It runs entirely in your browser — the file never leaves your machine — and reconstructs the metadata from the messages in the database, then hands you a metadata.yaml to drop back next to the .db3 so ros2 bag play works again.

What this does / doesn't do. This page only rebuilds metadata.yaml from an
    intact database — the most common crash case. It can't checkpoint a leftover -wal or salvage a
    corrupt .db3, and it loads the whole file into memory, so multi-GB bags should use the
    command-line tool instead:

    
pip install ros2bag-repairer
ros2bag-repair my_bag/                 # rebuild metadata in place
ros2bag-repair my_bag/ --force-recover # salvage a corrupt .db3
